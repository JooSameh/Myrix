# Premium Portfolio Website

Showcase your design expertise with a premium portfolio website that highlights your work, engages clients, and drives conversions through stunning visuals and interactive elements.

## Tech Stack

- **Framework:** React + TypeScript + Vite
- **Styling:** Tailwind CSS v4
- **Animation:** Motion
- **Icons:** Lucide React

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Deploying to Vercel

This project is pre-configured for zero-config deployment on Vercel via `vercel.json`:

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Import the project in the [Vercel Dashboard](https://vercel.com/new).
3. Keep the default **Vite** preset (`npm run build`, output directory `dist`) and click **Deploy**.
